# SIC48 Predictor

Streamlit web app for 48-hour SIC risk prediction.

## Run locally

```powershell
python -m streamlit run model_routeB_frontend.py
```

## Deploy

Deploy with Streamlit Community Cloud:

1. Push this folder to a GitHub repository.
2. Create a new app in Streamlit Community Cloud.
3. Select the repository, branch, and `model_routeB_frontend.py` as the main file.
4. Deploy.
